- 打印当届承诺书，由队员手写签名，再扫描或拍照。核对文字与签名完整清晰。
- 由实际使用记录汇总 AI 使用说明。截图中的 AI 使用说明通用命名写法与示例有出入，目录以含 `ai` 的页面示例为准，上传前再核对系统。
- 赛题要求提供支撑材料或使用了自编程序时，按竞赛要求准备。建议用 ZIP 或 RAR，包含可运行源程序、必要的自备数据和结果，赛题原始数据留在解题区。组委会集体报名通知也要求自编源程序随支撑材料提供。[组委会关于论文提交的说明](https://m.saikr.com/contest/notice_detail/47643)
- 逐个打开最终文件，核对命名、格式、大小、题号、队号和版本。上传到对应栏目后核对页面所选题号和提交状态。
