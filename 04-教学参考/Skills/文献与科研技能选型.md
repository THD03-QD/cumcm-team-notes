## 首批安装与备选审阅

| 顺序 | Skill | 具体用途与取舍 |
| --- | --- | --- |
| 1 | [literature-review](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/literature-review/SKILL.md) | 从小问出发设计检索词，筛选、去重，并按方法、适用条件与局限比较原文。竞赛可用精简流程，按需调用现有网页检索，保留检索记录。完整综述、外部 CLI 和 PDF 编译按任务选用。 |
| 2 | [citation-management](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/citation-management/SKILL.md) | 从 DOI 等标识取得元数据，检查重复、缺字段或不一致，整理 BibTeX。由主笔按实际模板选择在 Word 中录入或导入文献库。上游的联网核验脚本用 Python `requests`。 |
| 可选第 3 个 | [peer-review](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/peer-review/SKILL.md) | 有完整草稿时做一次独立审阅，找出论断缺证据、方法写不全、结果或引用对不上等问题。上游提供本地辅助脚本。项目已有交稿复核，可在第一轮交叉审阅遇到具体困难后再加。 |

进入 `math-modeling-solver` 的文献阶段时，按[文献检索与引用](../../02-论文/文献检索与引用.md)调用本项目的两项文献 Skill。上游提到的 `math-modeling-paper/references/literature-review.md` 属于另一套技能目录。

## 另找到的 GitHub 候选

- **citation-management** 补上可重复的书目核验和导出，适合与检索技能配对。[上游 GitHub](https://github.com/K-Dense-AI/scientific-agent-skills/blob/main/skills/citation-management/SKILL.md)
- **doi-bibtex** 输入 DOI 后抓取条目并写入 `.bib`，适合将来走 LaTeX、只需补少量已知 DOI 的情况。[scholar-kit 上游说明](https://github.com/yy/scholar-kit#doi-bibtex)

若队伍按 Word 主稿长期维护多条引用，可评估 Zotero 的 Word 插件，用它插入正文引文和统一更新参考文献。引用样式以当届模板为准。[Zotero Word 插件文档](https://www.zotero.org/support/word_processor_plugin_usage)
