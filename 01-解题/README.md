# 解题

从[拿题后工作流](拿题后工作流.md)开始，先完成选题和小问任务交接。

1. **读题并拆问。** 将题面和原始附件放入[原题与附件](原题与附件/)，保留原件。用[单题记录模板](单题记录模板.md)逐问记下交付量、单位、约束、输入字段和前后依赖。
2. **确定模型和基线。** 写清变量、关键假设、理由与适用条件，先做一个能回答该问的基线。模型选择和推导与该问的入口脚本一起放进[模型与代码](模型与代码/)。
3. **运行并出首图。** 默认使用本机已验证的 MATLAB R2026b。用脚本保存参数、结果表和运行方法，再按[论文插图指南](../02-论文/论文插图指南.md)选图和绘制。反馈控制或多模块动态系统按题意选用 Simulink。
4. **检验并迭代。** 用解析特例、边界条件或独立实现核对计算。数据题用保留的数据检验实际表现，决策题回代约束，并检查关键参数扰动是否改变结论。发现偏差时回查输入、假设或模型，重跑后同步结果。
5. **交给主笔。** 在[结果与检验](结果与检验/)按小问保留结果表、首图、检验记录和一段结论。每个关键数字应能定位到结果表字段和运行入口。由另一位队员独立复算一个关键数字，再进入[论文写作](../02-论文/README.md)。

选模卡住时查[选模与检验](../04-教学参考/建模方法/选模与检验.md)，绘图需要调整时查[仿真与制图技能推荐](../04-教学参考/Skills/从仿真到论文图的技能推荐.md)。
