# 论文

由主笔在[写作工作区](写作工作区/)维护可编辑稿。每问写之前，先拿到该问的假设与理由、可运行代码、结果和检验，出处从[解题页](../01-解题/README.md)回查。

正式主稿直接用英文。主稿工具待官方模板发布后确定。正文目录、摘要和版本联动按[论文结构与返修](论文结构与返修.md)执行。

引用外部论文、数据、公式或参数时，按[文献检索与引用](文献检索与引用.md)核对题录、原文定位及适用条件。

1. **按小问写正文。** 说明这一问要回答什么、为什么选这个模型、如何求解、得到了什么。把验证结果和适用条件放在结论旁边。
2. **排公式和图表。** 按[论文插图指南](论文插图指南.md)从已核对的结果表重绘，保留脚本。核对坐标、单位、图题、表注和引用，在导出的 PDF 中检查公式、清晰度和分页。
3. **写摘要并交叉审阅。** 摘要最后写，逐问给出核心方法和有依据的结果。请队友把关键数字从摘要回查到正文、结果表和代码，再按[交稿前复核](交稿前复核.md)逐项检查。
4. **冻结终稿。** 用当届规则和发布的模板确认论文格式。导出最终 PDF，按平台命名放入[电子档论文](../03-提交/01-电子档论文/)。

从实际使用 AI 时开始记录工具、使用环节和人工核验情况。队员可将[AI 使用记录模板](AI使用记录模板.md)复制到[本地记录目录](AI使用记录/)，提交前按要求汇总成 PDF 并放入提交区。
