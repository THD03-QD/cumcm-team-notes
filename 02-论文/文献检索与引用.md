# 文献检索与引用

引用一篇论文时同时核对两件事。第一，作者、题名、年份、刊物和 DOI 等能回查。第二，原文的具体位置确实支持准备写进正文的那句话。

## 项目里的做法

1. **从小问写检索目标。** 先写清要找的是方法依据、参数出处、数据来源，还是用于对照的结果。用「研究对象＋方法或指标」构造中英文检索式。按题型使用学术检索和出版商页面，保留有效检索式及查询日期。
2. **筛到原始出处。** 以 DOI 或题名去重，优先读原始论文、公开数据的官方说明和所用算法的原文。核对题目场景、样本、前提和适用区间。若作者公开稿与正式发表版并存，记录所读版本，并核对引用条目对应的版本。
3. **分开核对内容与题录。** 在原文查到支持的章节、页码、公式或图表，再用 DOI 与出版商或 Crossref 核对书目信息。仅能看到摘要时，把可引用范围限定在摘要确实支持的表述。只有检索摘要或转述时，标记待核实。官方数据和技术报告没有 DOI 时，用发布机构、日期、版本和稳定链接标识。[Crossref REST API 说明](https://www.crossref.org/documentation/retrieve-metadata/rest-api)
4. **交给主笔。** 提供能直接引用的条目、正文落点和一句证据说明。Word 按赛方模板插入引用；使用 Zotero 时通过 Word 插件统一更新。最后双向检查正文引用和条目，再检查参数、公式、图和对照结论有没有对应来源。

| 文献条目或 DOI | 支持正文哪句话 | 原文定位 | 适用条件或限制 | 核对状态 |
| --- | --- | --- | --- | --- |
| | | | | 题录已核 / 原文已核 / 待核 |

## 一个已经核对的例子

用 `out-of-sample tests forecasting accuracy fixed rolling origin` 找到 Tashman 的论文，并在出版商页和 Crossref 交叉核对题录。可用来支持「预测评价可以比较固定起点和滚动起点的样本外检验设计」，证据位置是摘要和第 3 节。某道赛题的具体切分年份和误差由本队自己的数据与复算结果支持。

Tashman, L. J. (2000). Out-of-sample tests of forecasting accuracy: an analysis and review. *International Journal of Forecasting*, 16(4), 437–450. [DOI](https://doi.org/10.1016/S0169-2070(00)00065-0) · [出版商原文页](https://www.sciencedirect.com/science/article/pii/S0169207000000650)
