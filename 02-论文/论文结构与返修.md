截图的前八项可作为正文框架。正式主稿直接用英文，按当届题面和模板确定版式及主稿工具。2026 亚太杯英文赛项已明确摘要页在第一页，每页顶部有参赛编号和页码。论文中的身份信息按要求仅保留参赛编号。题目要求的建议归入对应小问或模型评价。截图末尾的学习心得属于课程样例，签署的正式承诺书放[单独的提交栏目](../03-提交/README.md)。目录、页数、特别摘要或短文等以当届题面和模板为准。[组委会正式规则，第 3–5 页](https://m.saikr.com/contest/notice_detail/49353)

## 英文主稿骨架

| 写进论文的部分 | 写到什么程度 |
| --- | --- |
| Summary Sheet | 放第一页，摘要最后定稿。逐问给出方法、关键结果、单位和结论。 |
| Problem Background and Restatement | 交代背景、目标、输入和输出。逐问重述真正要解决的任务。 |
| Problem Analysis | 说清小问间的依赖、关键约束和为何采用这条建模路线。 |
| Assumptions and Notation | 写假设及依据，统一符号和量纲。需要时单列数据来源与预处理。 |
| Model Development, Solution, and Results | 推荐按小问写，每问从假设和公式接到求解过程、结果图表与本问答案。官方模板要求分别设立模型建立、求解等章节时，按模板拆分，并用统一的小问编号对应。 |
| Model Validation and Evaluation | 检验交代检验设计、量化结果和偏差。评价说明适用条件、局限、可推广范围与题面要求的建议。有些检验可以放在各问内并在这里归纳。 |
| References and Appendices | 参考文献与正文引用对应。附录按规则和题面提供程序及必要的补充资料，让关键结果可回查。 |

主笔可以在选题后先搭建英文标题、术语、单位和小问占位。每问结果通过复核后再填写数值、图表与结论。结果交接时一并确认代码版本、结果表和绘图输入，避免主稿出现无法追溯的数字。

## 返修顺序

1. **定位。** 给反馈标小问和稿件位置，明确是文字排版、引证，还是数据、公式、模型、结果。记录上一版和负责处理的队员。
2. **核实并决定。** 文字意见回查原稿，数据或方法意见回查原始附件、假设和代码。能复现问题再修改。受影响范围和预期证据写进记录。
3. **从源头修改。** 如果变更数据、参数、约束或代码，先重算受影响的小问，再沿依赖重跑后问。核对新旧结果的差异、单位和约束是否仍成立。
4. **同步主稿和附件。** 按同一版本更新结果表、图、图注、正文、摘要、附录及支撑材料。主笔复看数字和交叉引用，复核人核对至少一个受影响的关键结果。
5. **重新导出并关闭意见。** 查看新 PDF 的改动页、相邻页和摘要。冻结后若需要重开，保留上一版，再统一生成并复核新的提交组合。

例：问题一的单位换算改正后，在问题一重新导出带版本的结果表。如果问题二读取其中某一列，就重新跑问题二，并回查对应图表、两问的正文与摘要。打包前核对压缩包中的结果和附录所述版本一致。
