# 全国大学生数学建模竞赛备赛库

队友首次使用时，从 GitHub 仓库的 Code 按钮复制 HTTPS 地址，用 `git clone <地址>` 下载，在 Obsidian 中选择「打开本地仓库」并选中克隆所得文件夹。在 GitHub 网页也可以从此页直接阅读。

| 入口 | 第一次训练怎么用 |
| --- | --- |
| [赛前准备](01-备赛/训练路线.md) | 用一道往届题走完读题、求解和交叉复核 |
| [模型选择](02-方法/选模与检验.md) | 按题目要求的输出找基线和检验方法 |
| [训练记录模板](03-真题训练/单题记录模板.md) | 每道题复制一份，记录结果和复现入口 |
| [论文复核](04-论文/交稿前复核.md) | 逐问回查数字、图表和结论 |
| [技能对比](05-Skills/国赛技能对比.md) | 按队伍当前遇到的问题选择参考资料 |

### 队内协作

开始前运行 `git pull --ff-only`。同一道题由一人维护训练记录，其他队员分别维护求解代码和论文草稿。用相对路径关联数据、脚本与图表。提交前用 `git status` 核对改动，提交后用 `git push` 同步。历史版本可在 Git 提交记录中查看。
