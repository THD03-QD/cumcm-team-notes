# 数学建模队伍工作台

当前项目用于 2026 亚太杯英文赛项。[拿题后工作流](01-解题/拿题后工作流.md)串起选题、逐问求解、英文主稿、返修和提交。你负责主笔，队友逐问交付可以复算的结果。

| 入口 | 打开后做什么 |
| --- | --- |
| [01 解题](01-解题/README.md) | 读题拆问、建模求解、做检验并交接结果 |
| [02 论文](02-论文/README.md) | 按每问的证据写正文，排图表，交叉复核 |
| [03 提交](03-提交/README.md) | 按平台的四个栏目准备终稿并核对命名 |
| [04 教学参考](04-教学参考/README.md) | 单独阅读历年题索引、讲义、方法和技能对比 |

队友可克隆本仓库，在 Obsidian 中打开克隆目录，也可直接从 GitHub 阅读这些说明。赛题附件、实际求解材料、稿件、AI 使用原始记录及正式上传件放在各阶段的本地工作目录，队内通过授权渠道交接。
